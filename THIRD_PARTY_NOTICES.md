# Лицензии компонентов

Основной код San1C распространяется по лицензии MIT из файла LICENSE.

Внешние компоненты сохраняют собственные лицензии. Тексты лицензий находятся в каталоге licenses.

| Компонент | Лицензия | Текст лицензии |
| --- | --- | --- |
| Inter Variable, локально поставляемый шрифт | SIL Open Font License 1.1 | [Текст лицензии](licenses/Inter-OFL-1.1.txt) |
| React и React DOM | MIT | [Текст лицензии](licenses/React-MIT.txt) |
| Recharts | MIT | [Текст лицензии](licenses/Recharts-MIT.txt) |
| Lucide React | ISC и MIT для элементов, производных от Feather | [Текст лицензии](licenses/Lucide-ISC-MIT.txt) |
| Метаданные учебного эксперимента 1С | MIT, правообладатель указан в файле | [Текст лицензии](integrations/1c/experiment/METADATA-LICENSE.txt) |

Полные исходные тексты шрифтов и библиотек устанавливаются из npm согласно frontend/package-lock.json. Сборка приложения включает перечисленные клиентские библиотеки и шрифт.
