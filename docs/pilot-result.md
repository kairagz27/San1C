# Готовность первого подключения San1C

Проверка выполнена 23 ноября 2026 года. Лабораторная связка подтвердила путь от документов в файловой ИБ через нативный запрос и собранную Конфигуратором внешнюю обработку до рабочего экрана San1C. **Для начала бизнес-пилота требуется тестовая копия конкретного релиза УТ Казахстан 3.4.** Клиент подтвердил отсутствие копии и экспорта метаданных. Релиз, организацию, точки и контрольный штатный отчёт предстоит выбрать по полученной базе. [Паспорт, перечень объектов и полей, шаги специалиста](pilot.md)

## Как повторить

Из корня репозитория запустите приложение и проверки. Для нового учебного прогона на Windows нужны установленная тестовая платформа, Docker, Python и Firefox Playwright. Нативный сценарий создаёт новую ИБ и обращается только к выделенному приёмнику лаборатории на 8448. Первое открытие собственной сборки подтвердите в штатном диалоге 1С.

```powershell
docker compose up --build -d --wait
docker compose exec -T -e 'TEST_POSTGRES_URL=postgresql+psycopg://san1c@/san1c?host=/var/run/postgresql' app python -m pytest -q -p no:cacheprovider
.\.venv\Scripts\python -m pytest deploy/pilot/test_pilot.py -q -p no:cacheprovider
.\.venv\Scripts\python frontend/tests/browser_smoke.py --browser msedge --screenshots .verification/pilot-demo

$designer = Join-Path $env:LOCALAPPDATA 'Programs\San1C-Lab\file-platform\1cv8t\8.5.1.1343\bin\1cv8t.exe'
py -3 -X utf8 integrations/1c/lab/transport/lab.py up pilot
py -3 -X utf8 integrations/1c/experiment/pilot.py --platform "$designer"
```

Для проверки браузера после успешного нативного сценария подставьте каталог прогона, который напечатал `pilot.py`. Команда входит в отдельный Firefox-профиль с CA соответствующего стенда.

```powershell
$work = Get-ChildItem "$env:LOCALAPPDATA\San1C\lab\pilot-runs" -Directory |
    Where-Object { Test-Path (Join-Path $_.FullName 'native-schedule.json') } |
    Sort-Object Name -Descending | Select-Object -First 1
.\.venv\Scripts\python frontend/tests/pilot_smoke.py --url https://localhost:8448 --state "$env:LOCALAPPDATA/San1C/lab/transport/pilot" --control (Join-Path $work.FullName 'control-final.csv') --screenshot-dir .verification/pilot-native
```

Чтобы открыть отчёт самому после браузерной проверки, запустите Firefox с подготовленным профилем этой лаборатории. В форме входа выберите «Владелец». Его пароль хранится в поле `owner_password` файла `credentials.json` в каталоге `$state`. Для просмотра итогов установите период 9–22 ноября 2026 года и выберите обе точки.

```powershell
$state = Join-Path $env:LOCALAPPDATA 'San1C\lab\transport\pilot'
$caHash = (Get-FileHash (Join-Path $state 'ca.pem') -Algorithm SHA256).Hash.ToLowerInvariant()
$firefoxDirectory = Join-Path $state ('firefox-' + $caHash.Substring(0, 16))
.\.venv\Scripts\python -m playwright open -b firefox --user-data-dir "$firefoxDirectory" 'https://localhost:8448/#/live/sales'
```

HTTP-фикстура имеет собственную базу и токен. Повтор одинакового JSON и восстановление после разрыва воспроизводятся отдельно.

```powershell
py -3 -X utf8 integrations/1c/lab/transport/lab.py up fixture
py -3 -X utf8 integrations/1c/lab/transport/lab.py send-fixture
py -3 -X utf8 integrations/1c/lab/transport/interrupted_fixture.py
```

На PostgreSQL прошли 28 тестов backend, включая сверку, неизменяемую историю, доступ по ролям, отзыв ключа во время незавершённой передачи и параллельную замену снимков. Семь тестов пакета оператора прошли отдельно. Проверка демо охватила четыре экрана в Edge, клавиатурную навигацию и мобильную ширину 390 px.
