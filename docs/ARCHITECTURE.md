# Архитектура

## Поток данных

Информационная база 1С → запрос из согласованного профиля → внешняя обработка BSL → исходящий HTTPS → FastAPI → PostgreSQL → отчёты React для владельца.

Для сверки владелец выгружает штатный отчёт из 1С в CSV. San1C сравнивает его по каждому дню и точке с полными снимками источника и сохраняет результат.

Обработка считывает операции в той же информационной базе встроенным запросом. Приёмник заменяет согласованный дневной снимок одной транзакцией. Повтор не удваивает факты, а неполные дни исключаются из аналитики до повторного подтверждения.

Демо и пилот компании используют разные наборы данных. Развёртывание компании создаёт собственный PostgreSQL, HTTPS-адрес, закрытый каталог секретов и профиль источника. Владелец читает отчёты, администратор дополнительно управляет ключом импорта.

Компоненты описаны в README. Развёртывание и восстановление описаны в deploy/pilot/README.md.
