# Сообщить об уязвимости

Не публикуйте детали ещё не исправленной уязвимости в открытой задаче. Напишите владельцу репозитория напрямую через GitHub и приложите способ воспроизведения, влияние и версию затронутой сборки.

Не прикладывайте реальные токены, пароли, персональные данные или клиентскую базу 1С. Достаточно тестового примера без секретов.
