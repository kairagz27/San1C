# Участие в проекте

Обсуждения и сообщения об ошибках можно писать на русском или английском языке. Перед изменением укажите, какое поведение нужно владельцу или специалисту 1С и как его проверить.

## Подготовить среду

Нужны Git, Docker с Compose v2, Python 3.12 и Node.js 24. Запустите PostgreSQL и приложение:

    docker compose up --build -d --wait

Приложение доступно по адресу http://127.0.0.1:8088. Фронтенд собирается в Docker-образе. Для локальных изменений клиентского кода выполните npm ci и npm run build из каталога frontend.

## Проверить изменения

Запустите тесты backend на PostgreSQL из корня репозитория:

    docker compose exec -T -e 'TEST_POSTGRES_URL=postgresql+psycopg://san1c@/san1c?host=/var/run/postgresql' app python -m pytest -q -p no:cacheprovider

Укажите результат проверок в запросе на слияние. Для изменения интерфейса приложите скриншот настольного и, если затронут, мобильного вида. Для контракта импорта 1С опишите совместимость на конкретной учебной базе или тестовой копии. Учебную конфигурацию нельзя выдавать за проверенную УТ Казахстан.

## Данные и доступ

Не добавляйте в репозиторий пароли, ключи, сертификаты, реальные данные покупателей, рабочие выгрузки 1С, дампы PostgreSQL или конфигурацию, полученную без разрешения. Изменения схемы БД оформляйте миграцией Alembic и проверяйте на пустом и существующем экземплярах.
