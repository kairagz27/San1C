# Первый нативный тест San1C на платформе 1С

23 ноября 2026 года учебная платформа **8.5.1.1343** дважды выгрузила из отдельной файловой ИБ **УчебнаяТорговля 1.0.0.1** один закрытый день за **16 ноября 2026 года**. Конфигуратор собрал внешнюю обработку из исходников. В сеансе «1С:Предприятие» обработка выполнила нативный запрос по проведённым документам, сформировала две строки и передала их по HTTPS. В рабочем режиме San1C на экране «Продажи» подтверждены **10 000 ₸ продаж, 2 000 ₸ возвратов и 8 000 ₸ выручки**. [Экран после повтора](results/2026-11-23/native-sales.png) · [Проверенная внешняя обработка](results/2026-11-23/San1CВыгрузка.epf)

## Условия и результат

В первой фазе обработка провела продажу пяти единиц товара по 2 000 ₸ и возврат одной единицы за 2 000 ₸ по организации «Учебная организация», точке «Учебная точка». Для независимого контроля отдельный агрегирующий запрос 1С прочитал проведённые строки за эту дату с фильтрами организации и точки. Повторный сеанс открыл ту же ИБ и ту же обработку и повторно прочитал документы. Обе квитанции получили статус `accepted` из-за новой метки времени чтения. После повтора прямой запрос к PostgreSQL подтвердил один актуальный снимок за день, две уникальные строки, два разных документа, одну точку и ноль ошибок по дню. ## Платформа, база и транспорт

В «Загрузках» получен архив `training_8_5_1_1343.zip`. Windows подтвердила подпись LLC 1C-Soft на установщике, MSI, CAB и исполняемом файле. Системная установка откатилась при записи в системный каталог шрифтов, полному административному образу не хватило места. Файлы для файловой версии и русского языка извлечены из MSI/CAB с исходными именами в сжатый каталог текущего пользователя. Сценарий запустил Конфигуратор и клиент непосредственно через `1cv8t.exe`. Для экономии места было также включено штатное NTFS-сжатие локальных зависимостей проекта в `.venv` и `frontend/node_modules`. При первом запуске устранены две причины ошибки. Путь к файловой базе теперь заключён в одинарные кавычки строки соединения 1С. Кодировка для файлов JSON и тела HTTP передаётся строкой `"UTF-8"`. Конфигуратор и клиент завершили обе фазы после этих исправлений.

## Повторить на этом компьютере

В интерактивном PowerShell выполните команды из репозитория. При первом открытии новой собранной обработки 1С показывает её путь. Выберите **Yes / Да** для `San1CВыгрузка.epf` текущего прогона. Каждый запуск сценария создаёт новую изолированную файловую ИБ. Проверка API выполняется сразу после каждой выгрузки.

```powershell
Set-Location 'C:\Users\MrForest\Documents\ChatGPT\1C'
$designer = Join-Path $env:LOCALAPPDATA 'Programs\San1C-Lab\file-platform\1cv8t\8.5.1.1343\bin\1cv8t.exe'
py -3 integrations/1c/lab/transport/lab.py up native
py -3 integrations/1c/experiment/run.py --platform "$designer"
if ($LASTEXITCODE -eq 0) {
    py -3 integrations/1c/lab/transport/lab.py verify native
    if ($LASTEXITCODE -eq 0) { .\.venv\Scripts\python integrations/1c/lab/transport/browser.py native }
}
```

Для просмотра дашборда этого стенда используется Firefox с доверием к его локальному CA. Инструкция по интерактивному входу и расположение тестового пароля приведены в [документации HTTPS-стенда](transport/README.md). Рабочая страница отображает данные после входа и выбора даты 16.11.2026. [Рабочий экран нативного стенда](https://localhost:8446/#/live/sales)

## Отдельная проверка API на фикстуре

На другом стенде `https://127.0.0.1:8447` один и тот же JSON получил `accepted` и `unchanged`. Его собственный API и экран также показали 10 000 ₸, 2 000 ₸, 8 000 ₸ и один документ продажи. Для каждого из двух HTTPS-стендов проверено доверие своему CA и отклонение сертификата чужого CA. Команды повторения фикстуры:

```powershell
py -3 integrations/1c/lab/transport/lab.py up fixture
py -3 integrations/1c/lab/transport/lab.py send-fixture
.\.venv\Scripts\python integrations/1c/lab/transport/browser.py fixture
```
