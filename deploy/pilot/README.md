# Экземпляр San1C для одной компании

Одна установка обслуживает одну организацию и одну базу 1С. У неё собственные PostgreSQL 17, тома, сеть Docker и HTTPS-адрес. Caddy публикует интерфейс и API на одном адресе. Приложение обращается к PostgreSQL через Unix-сокет. Доступ к Docker и каталогу оператора даёт полный контроль над этой установкой.

## Что согласовать с клиентом

Запишите организацию, точный релиз УТ Казахстан 3.4, версию платформы, режим базы, доработки и разрешение на запуск внешней обработки. Нужна разрешённая тестовая копия и доступ на чтение продаж и возвратов **всех согласованных точек**. Получите имя штатного отчёта, настройки периода и точек, основу НДС, валюту и поле итоговой суммы в KZT. Зафиксируйте ответственного специалиста 1С, администратора сервера и владельца отчёта. Подготовьте имя HTTPS-сервера и сертификат, которому доверяет компьютер или сервер, исполняющий BSL.

## Установить

Установите Docker Compose с поддержкой `!reset` (2.24.4+) и Python 3.10+. Команды выполняются из корня репозитория. На Windows используйте `py -3` вместо `python`. Ниже `magazin` — уникальный код компании, `r1` — уникальная метка сборки. Пример адреса, частный IP и пути замените значениями площадки. Файл цепочки должен начинаться сертификатом сервера.

```sh
python deploy/pilot/pilot.py magazin init --name "Название компании" --profile /private/verified/profile.json --host sales.example.kz --bind 192.168.10.20 --port 443 --certificate /private/tls/fullchain.pem --private-key /private/tls/key.pem --timezone Asia/Almaty
python deploy/pilot/pilot.py magazin up --release r1
```

Для частного УЦ добавьте `--ca /private/tls/root.pem`. Обеспечьте разрешение DNS-имени, доступность указанного адреса и исходящий HTTPS из среды 1С. При продлении сертификата замените `certs/fullchain.pem` и `certs/key.pem` в приватном каталоге, затем остановите и снова запустите экземпляр. Для изолированной пробы на том же компьютере используйте `--host localhost --bind 127.0.0.1 --port 8450`, без опций сертификата. Тогда Caddy выдаст локальный сертификат и скрипт скопирует публичный корень в `ca.pem`.

Конфигурация и секреты находятся в `%LOCALAPPDATA%\San1C\pilot\magazin` на Windows или `~/.local/share/San1C/pilot/magazin` на Linux. В Windows доступ предоставляется текущему пользователю и SYSTEM, в Linux каталог имеет режим 0700. В `credentials.json` находятся отдельно сгенерированные `owner_password`, `admin_password` и `upload_token`. Оператор передаёт каждому участнику его секрет по приватному каналу. Контейнер приложения получает только хеши. Доверенный профиль и запрос копируются в каталог экземпляра и монтируются с правом чтения. В Compose-командах код компании определяет имя проекта и томов.

## Подключить базу и принять первую загрузку

1. Специалист сверяет метаданные **на копии конкретного релиза**, проверяет поле суммы после скидок с НДС в KZT, проведение и даты возвратов, UUID организации и идентификаторы одной или двух точек. Согласованный профиль и шаблон устанавливаются на сервер и в обработку. Учебный профиль подходит для проверки лаборатории. Совместимость с УТ клиента требует отдельного прогона. [Инструкция для специалиста 1С](../../integrations/1c/README.md)
2. Администратор входит на `https://sales.example.kz/#/live/source` с ролью администратора. В обработке укажите имя HTTPS-сервера, порт, токен и доверенный УЦ. Запустите проверку подключения, проверьте профиль и результат запроса к API.
3. Выгрузите две закрытые недели полными днями по всем согласованным точкам. Проверьте покрытие и последнюю попытку. После исправления повторите весь соответствующий день. При переносе документа на другую дату повторите оба дня.
4. Владелец входит с ролью владельца на `/#/live/sales`, выбирает те же даты и точку, сопоставляет продажи, возвраты и итог со штатным отчётом и сохраняет результат сверки. Затем открывает детализацию точки и сохраняет виджет из вопроса на русском. Файл `qa_control.csv` в этом каталоге служит синтетическим контролем лаборатории. Клиент предоставляет собственный экспорт.
5. Специалист проверяет доступный механизм расписания для фактического варианта базы и запускает общий адаптер под согласованной учётной записью. До подтверждения нескольких запусков и восстановления пропуска оператор использует ручной диапазон. Перед отключением остановите расписание на стороне 1С и отзовите доступ загрузки.

## Управлять доступом

Администратор отключает загрузку или выдаёт новый токен в разделе «Источник 1С». Владелец читает отчёты, сверяет суммы и сохраняет виджеты. Для тех же операций с сервера используйте команды ниже. Административный API требует сессию администратора, эндпоинт приёма требует отдельный bearer-токен.

```sh
python deploy/pilot/pilot.py magazin disable
python deploy/pilot/pilot.py magazin rotate-upload
python deploy/pilot/pilot.py magazin rotate-password owner
python deploy/pilot/pilot.py magazin rotate-password admin
```

`disable` сохраняет отзыв в PostgreSQL и завершает приём по старому токену, отчёты остаются доступны. `rotate-upload` выдаёт новый ключ и включает приём. CLI помещает ключ в `credentials.json` без вывода в терминал. Укажите его в обработке. При ротации через интерфейс новый ключ показывается администратору один раз. Обновите его у специалиста и в защищённом хранилище оператора. После ротации пароля веб-сессии соответствующей роли теряют доступ. Команда `stop` останавливает и HTTPS, и приложение, и БД с сохранением томов.

## Резервная копия, восстановление, откат

```sh
python deploy/pilot/pilot.py magazin backup --with-image
python deploy/pilot/pilot.py magazin restore /private/offsite/20261123T060201359019Z
python deploy/pilot/pilot.py magazin rotate-upload
```

`backup` создаёт согласованный `pg_dump` в custom-формате, копирует профиль и запрос, записывает SHA-256, метку и ID образа в `manifest.json`. Ключ `--with-image` добавляет точный образ для восстановления на новом хосте. Без него соответствующий образ должен быть доступен локально. Команда выводит каталог готовой копии. Храните копии на независимом носителе с шифрованием и ограниченным доступом. Приватные ключи TLS и пароли участников храните отдельно. Для нового хоста заново выполните `init` с тем же кодом компании и сертификатом площадки, затем `restore`. Имена БД и теги образов задаёт CLI.

`restore` проверяет контрольные суммы, создаёт новую БД в отдельном кластере компании, восстанавливает её одной транзакцией, применяет миграции архивной версии и только после этого переводит HTTPS на восстановленную БД. При восстановлении действующие сессии удаляются, а импорт принудительно выключается **до открытия HTTP**. Администратор сверяет покрытие, суммы и сохранённые результаты, выпускает новый токен и повторяет даты, изменённые после копии. Пароли для веб-интерфейса берутся из защищённого каталога целевого экземпляра. Предыдущая БД при переключении сохраняется.

Чтобы проверить восстановление без переключения рабочего адреса, инициализируйте отдельный стенд. Копия другой компании отклоняется по умолчанию. Для указанной команды нужен свежий экземпляр либо экземпляр, заранее привязанный к тому же донору.

```sh
python deploy/pilot/pilot.py magazin-recovery init --recovery-for magazin --name "Контроль восстановления" --profile /private/verified/profile.json --port 8451
python deploy/pilot/pilot.py magazin-recovery restore /private/offsite/20261123T060201359019Z --from-company magazin
```

Обновление собирает новую версию до окна обслуживания. Затем останавливает входящий трафик, создаёт предобновленческую копию и запускает новый образ. Успешное обновление выводит путь к точке отката. Для нового проверенного профиля добавьте `--profile /private/new/profile.json`. Уже созданный тег обозначает зафиксированную сборку, для другого исходного кода укажите новый тег.

```sh
python deploy/pilot/pilot.py magazin upgrade r2
python deploy/pilot/pilot.py magazin rollback /private/path/from/upgrade
python deploy/pilot/pilot.py magazin rotate-upload
```

Откат возвращает приложение и данные к моменту контрольной копии. Сохраните текущее состояние командой `backup` перед плановым переключением, если после обновления появились операции, сверки или виджеты. Остановите расписание, согласуйте окно и перечень повторных выгрузок с оператором.
